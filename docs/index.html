json-render-table

Declarative, lightweight JSON table rendering for modern browsers. Powered by json-traversal recipe transformations and @keshavsoft/json-to-tag DOM synthesis.

Interactive Live Demo GitHub Repository npm Package

The Architecture Story

Instead of hard-coded string templates or bulky component runtimes, json-render-table decouples table generation into three pure declarative phases:

1. Raw Input
Data & Columns

JSON records array and optional custom columns

2. Recipes
Flavor Blueprint

Declarative transformation recipe (simple, headerOnly, withBodyAndFooter)

3. DOM Spec
json-traversal

Produces pure DOM tree specification JSON

4. Render
json-to-tag

Generates native HTML table nodes mounted directly into your container

Quick Installation & Usage

1. Install via npm
npm install json-render-table
2. Import in bundlers (Vite / Webpack)
import render from "json-render-table";

render({
  flavor: "simple",
  data: myRecords,
  targetHtmlId: "table-container"
});
Direct Browser Script (CDN / dist)
<!-- Target DOM element -->
<div id="table-container"></div>

<!-- Load standalone build -->
<script type="module" src="./dist/v8/min.js"></script>

<script>
  window.renderTable({
    flavor: "withBodyAndFooter",
    data: [
      { id: 101, product: "Laptop", price: 999 },
      { id: 102, product: "Mouse", price: 29 }
    ],
    targetHtmlId: "table-container"
  });
</script>
